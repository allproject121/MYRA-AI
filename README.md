# MYRA AI Assistant (Android Native)

A futuristic sci-fi voice AI companion built natively for Android using Kotlin, Android SDK 34, and Google Gemini AI intelligence.

## Features

- **Pulsing Sci-Fi Orb & Audio Waveform**: Reactive visual orb transitioning smoothly between IDLE, LISTENING, THINKING, and SPEAKING states with live audio amplitude visualization.
- **Multilingual Voice & Chat Interface**: Automatic detection and conversational response in natural Hinglish, Hindi, and English with personality tuning (💖 GF Mode, 💼 Professional, 🤖 Assistant).
- **Text-to-Speech (TTS) & Speech-to-Text (STT)**: Integrated Android TextToSpeech engine with speech rate/pitch modulation and SpeechRecognizer.
- **Real Device Hardware & System Tools**:
  - Camera Flashlight (Torch) hardware toggle
  - Live Battery telemetry with charging status
  - Storage & memory cache analyzer and cleaner
  - Instant screen lock
  - System clipboard management
  - Wi-Fi & Bluetooth controls
- **Communication & Speed Dial**:
  - Prime Contact instant speed dial, WhatsApp message dispatcher, and SMS composer
  - Direct contact lookup by name or relationship (Mom, Dad, Rahul, etc.)
  - Emergency SOS alert with GPS coordinates
- **Incoming Call Screening Assistant**:
  - Incoming call monitor service with voice announcement ("Sir, [Caller] ka call aa raha hai. Uthau ya reject karu?")
  - Voice decision listening ("Uthao" to accept, "Reject" to decline)
- **Visual Social Media Automation Agent**:
  - Automated drafting and posting for Instagram (Feed, Story, Reel) and Facebook (Post, Feed)
  - AI Smart Caption generator
  - Safe closed-loop user confirmation gate before publishing
- **Phone Utilities & Security Toolbox**:
  - 16-Character Secure Password Generator with one-tap copy
  - Canvas-rendered QR Code Generator
  - Real-time Network Speed Benchmark (Ping, Download, Upload)
  - Quick Voice Notes & Memos
  - Camera Room Sentry with motion detection simulation and alarm
  - PIN Protection (keypad access verification)
- **Gemini Live & REST API Integration**:
  - Gemini 2.5 Flash / 1.5 Flash support via Google Generative Language API
  - Built-in intelligent offline personality fallback engine ensuring immediate responsiveness out-of-the-box
